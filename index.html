Bienvenue dans ton espace membre !

BALDUR PHONE RESET t'accompagne pour réinitialiser ton téléphone.

Choisis ton téléphone

Réinitialiser un Samsung

1. Ouvre les Paramètres du téléphone.
2. Appuie sur Gestion globale.
3. Choisis Réinitialisation.
4. Appuie sur Réinitialiser toutes les données.
5. Lis les avertissements et confirme si tu souhaites continuer.

Les noms des menus peuvent varier selon le modèle.

Réinitialiser un Android

1. Ouvre les Paramètres.
2. Cherche Système ou Gestion globale.
3. Cherche Options de réinitialisation.
4. Sélectionne Effacer toutes les données.
5. Lis les avertissements avant de confirmer.

Réinitialisation à distance

Pour ton propre téléphone perdu ou bloqué, utilise le service officiel Google.

Attention : la réinitialisation efface les données. Après une réinitialisation, le téléphone peut demander le compte Google précédemment associé.
